# Blinkit Sales & Outlet Analysis Dashboard 📊

## 📌 Project Overview

The **Blinkit Sales & Outlet Analysis Dashboard** is an interactive **Power BI data analytics project** developed to analyze grocery sales performance and understand the factors influencing outlet and product performance.

The dashboard transforms raw Blinkit grocery sales data into meaningful business insights using **Power Query, DAX, and interactive Power BI visualizations**.

The main objective of this project is to provide a clear overview of sales performance and enable users to analyze sales based on **item type, fat content, outlet size, outlet location, outlet type, and outlet establishment year**.

---

## 🎯 Project Objectives

* Analyze overall grocery sales performance.
* Identify the best-performing product categories.
* Compare sales across different outlet types and sizes.
* Analyze sales based on outlet location.
* Understand the impact of item fat content on sales.
* Analyze outlet establishment trends over the years.
* Create an interactive dashboard for business performance monitoring.
* Convert raw data into useful and easy-to-understand visual insights.

## 🔍 Dashboard Analysis

### 1. Sales Performance

The dashboard provides an overall view of sales performance using KPI cards and visualizations.

Key metrics include:

* Total Sales
* Average Sales
* Number of Items
* Average Rating

These KPIs provide a quick overview of the business's overall performance.

### 2. Item Type Analysis

Sales are analyzed across different product categories, including:

* Fruits and Vegetables
* Snack Foods
* Household
* Frozen Foods
* Dairy
* Canned
* Baking Goods
* Health and Hygiene
* Meat
* Soft Drinks
* Breads
* Hard Drinks
* Others
* Starchy Foods
* Breakfast
* Seafood

This analysis helps identify which product categories contribute the most to overall sales.

### 3. Fat Content Analysis

The dashboard analyzes products based on their fat content:

* Low Fat
* Regular

This helps compare sales performance between different product fat-content categories.

### 4. Outlet Analysis

Outlet performance is analyzed using multiple dimensions:

* Outlet Type
* Outlet Size
* Outlet Location
* Outlet Establishment Year

This makes it possible to compare sales performance across different outlet characteristics.

### 5. Outlet Establishment Trend

The dashboard includes a trend analysis of outlet establishment over the years.

This visualization helps identify changes in sales performance across different outlet establishment years.

### 6. Outlet Size Analysis

Sales are compared across different outlet sizes:

* Small
* Medium
* High

This provides insight into how outlet size relates to overall sales performance.

### 7. Outlet Location Analysis

The dashboard compares sales across outlet location tiers:

* Tier 1
* Tier 2
* Tier 3

This helps identify which location type contributes more to overall sales.

### 8. Outlet Type Comparison

The dashboard compares major outlet types using:

* Total Sales
* Number of Items
* Average Sales
* Average Rating
* Item Visibility

This provides a detailed comparison of outlet performance.

## 🧹 Data Preparation

The raw dataset was prepared before creating the dashboard.

The data preparation process included:

1. Loading the grocery sales dataset into Power BI.
2. Inspecting the available columns and data types.
3. Cleaning and transforming the data using Power Query.
4. Preparing fields required for analysis.
5. Creating calculated measures using DAX.
6. Validating KPI calculations.
7. Building interactive visuals and dashboard components.

## 🧮 DAX & KPI Development

DAX measures were used to calculate important business metrics such as:

* Total Sales
* Average Sales
* Number of Items
* Average Rating

These measures were then used throughout the dashboard to create dynamic KPI cards and visualizations.
